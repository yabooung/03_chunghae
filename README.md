# 청해 — 바람의 장부

828년, 배 한 척과 오천 냥. 장보고의 시대, 신라·당·왜·발해의 바다를 누비는 캐주얼 교역·해전·탐험 게임.

- **장사** — 소문을 믿고 상자를 실어 나른다. 29개 항구, 11가지 물건, 계절풍과 세상 소식이 값을 흔든다. 항구마다 지역색이 다른 의뢰(관아 공물·신라방 위탁·상단 위탁·다자이후 납품·발해 공물·섬의 공물) — 그곳에서 나는 물건을 할인가로 사서 그것을 찾는 항구에 가져다주면 보수와 명성을 받는다.
- **해전** — 적의 다음 수를 읽고 맞받는 턴제 해전. 예고를 놓치면 크게 다친다. 현상 수배 두목 6명.
- **탐험** — 보물 지도를 따라 잠수(숨이 끊기면 건진 것을 다 잃는다), 발견지 27곳의 탐험 도감, 유물 8종.
- **난이도** — 바람(쉬움)·풍랑(보통)·태풍(어려움). 수치는 `src/core.js`의 `DIFFS` 표 하나에 있다. 상납을 못 내면 바로 끝나지 않고 빚으로 넘어간다(바람은 두 번, 나머지는 한 번). 판은 열두 번째 상납(세 해)에서 닫힌다.
- **이야기** — 선장(궁복·아라·도모)마다 막으로 나뉜 본 이야기(5·4·4막)와 선장마다 다른 결말 10개(+ 열두 번째 상납으로 닫는 「세 해의 장부」). 막은 사람의 한마디와 선택으로 열리고, 막 사이에는 예고 소식이 흘러오며, 마지막 선택과 결말 에필로그는 지나온 선택을 되비춘다(역사의 길·바다의 길·다른 길). 이야기 퀘스트 26줄기(항구 26곳에 하나씩 — 지역마다 그 땅의 사람과 물건으로 짠 지역 이야기 15줄기, 깃발이 결말 에필로그로 돌아온다), 막 사이에 끼어드는 장면 19개. 시세 오르내림과 사건은 소식창으로 흘러든다.
- **사전** — 바다에서 만나는 사람·항구·물건·제도·사건이 「사전」(典, 키 D)에 하나씩 열린다. 항목마다 「역사 기록」과 「게임 속 각색」을 나눠 적고 출전을 단다. 이야기·사건 글 속 낱말을 누르면 그 자리에서 항목을 펼친다.

## 실행

```bash
npm run build      # dist/index.html 한 파일로 묶는다(글꼴까지) → 인터넷 없이도 브라우저로 열면 된다
npm test           # 빠른 점검 (물길·새 게임·난이도별 봇 진행·저장 왕복·결말·사전)
npm run sim:battle   # 난이도별 해전 승률 (예고를 읽는 봇 / 아무 수나 누르는 봇)
npm run sim:economy  # 난이도별 상납 생존 · 상납 대비 재산 · 항해 사건 분포 (몇 분 걸린다)
npm run sim:dive     # 잠수 욕심별 기대값
npm run sim:story    # 선장 × 난이도마다 이야기를 끝까지 보려는 봇이 결말에 닿는 비율 (--assist 로 경제를 빼고 이야기 논리만)
```

의존성 없음. Node 18+만 있으면 된다. 스크린샷 점검은 `pip install playwright` 후 `npm run shots`.

## 구조

```
src/
  page.html   화면 뼈대와 스타일 (한지·먹·단청 — 색·글꼴·움직임 토큰이 맨 위 :root에 있다)
  core.js     규칙 엔진 — DOM 없음. node에서 require 해서 시뮬레이션할 수 있다
  codex.js    사전 항목(역사 기록·게임 속 각색·출전)과 여는 규칙 — DOM 없음
  ui.js       캔버스 해도, 모달, 소리, 입력, 흐름
  art/        손으로 짠 SVG 그림 — portraits.js: 인물 초상 34명(선장·선원·두목·이야기 인물)
  art/scenes.js 장면 그림 — 항구 29곳(원형 6 + 청해진), 사건 카드 30장, 두목·해적 배, 결말 13장 (캔버스)
assets/fonts/     게임 글자만 남긴 woff2 글꼴 6면(본문 400·600 · 제목 · 도장 2면 · 붓글씨)과 사용 허락(SIL OFL 1.1), faces.json(도장 글꼴 unicode-range)
tools/build.js   page·core·art·ui와 글꼴을 dist/index.html 하나로
tools/fonts.py   글꼴 부분 집합 만들기 (pip install fonttools brotli)
test/
  smoke.js       CI에서 매번 도는 빠른 점검
  sim/           밸런스 시뮬레이션 (경제·해전·잠수·이야기·항로)
  screenshots.py PC·모바일 화면 캡처 (Playwright)
docs/            설계 문서와 로드맵
```
